F5 Group Backup

Privacy Policy

Updated: 4 November 2026. This policy describes the intended practices of F5 Group Backup, a private website backup utility controlled by its operator.

Current status: connection setup is in progress. Unattended production backup has not been activated. The controls described below are requirements for activation and will be verified during setup.

Google data accessed

The utility requests the Google Drive drive.file permission to create and manage its backup files and associated metadata, such as file identifiers, names and sizes. Its intended workflow uses files created by this application. It does not request Gmail or Google Contacts data.

Purpose and use

Access is used for uploading encrypted backup archives, checking their integrity, restoring website data and applying the operator's retention policy. Google user data and backup contents are not used for advertising, sold, or used to train AI models.

Storage and protection

Backup contents must be encrypted by Restic before upload to the operator's Google Drive. Backup encryption passwords and the recovery secrets needed for the website are kept under separate operator-controlled custody. OAuth credentials and tokens belong in private operator-controlled configuration, outside public pages, source control and logs.

Access and service providers

Only the authorized operator is intended to manage the backup connection and repository. Google provides Drive storage and OAuth authorization. The utility does not intentionally publish or publicly share backup files. Other people are not given access for advertising, analytics or AI training.

Retention, deletion and revocation

The intended schedule is daily backup with 30 daily, 8 weekly and 3 monthly recovery points; these categories can overlap. It is not yet an active or verified schedule. The operator controls backup deletion and can revoke the Google connection from the Google Account permissions page. Revoking access stops future authorized access but does not automatically delete existing backup files.

Information pages

These static information pages contain no analytics, advertising scripts or sign-in forms. The hosting provider may process ordinary access logs. If published through GitHub Pages, visitor IP addresses are logged by GitHub for security purposes; see the GitHub Privacy Statement.

Contact and updates

For questions, access revocation or deletion requests, contact the operator using the user-support email shown on the Google authorization screen for F5 Group Backup. This policy will be updated if the utility's actual data practices change.
