F5 GROUP BACKUP

Private, encrypted website backups.

F5 Group Backup is an internal utility for the F5 Group website operator. It is designed to store and restore encrypted website backup archives in the operator's Google Drive account using Restic and rclone.

Setup in progress. The Google Drive connection is being configured. No unattended production backup has been activated.

What the utility does

  • Prepares a consistent website database and media backup after the operator approves the snapshot process.
  • Encrypts backup contents with Restic before upload.
  • Uses Google Drive to write, read, verify and manage the utility's backup files for recovery.

Google Drive access

The requested Google Drive permission is https://www.googleapis.com/auth/drive.file. The utility is intended to work with the files it creates for backup. It does not request access to Gmail or Google Contacts.

The operator authorizes the connection through Google. This information page does not provide a sign-in form, request Google passwords or collect OAuth credentials.

Read the F5 Group Backup Privacy Policy for the intended data practices, retention and access controls.

For support, contact the operator using the user-support email displayed on the Google authorization screen for F5 Group Backup. This page describes the backup utility; operational access remains controlled by the operator.
